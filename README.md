# AI From Zero to Production

A structured and beginner-friendly AI learning repository created from my handwritten AI notes.

The goal of this repository is to preserve the original concepts, examples, explanations, and learning flow from the source notes while presenting the content in a cleaner, more readable, and GitHub-friendly format.

---

## About This Repository

Artificial Intelligence includes many connected concepts, from basic AI and Machine Learning fundamentals to modern topics such as Generative AI, Prompt Engineering, Retrieval-Augmented Generation, AI Agents, and production systems.

Instead of organizing the material by day numbers, this repository organizes the notes by topic. This makes it easier to study a specific concept, revisit a section, and follow the overall learning path.

The content will be rewritten for:

- Better readability
- Clearer sentence flow
- Consistent terminology
- Professional Markdown formatting
- Easier topic navigation
- Better understanding for beginners

The original meaning and examples from the handwritten notes will be preserved.

## Content Principles

This repository follows four important principles.

### Preserve the original meaning

The explanations, examples, and concepts from the source notes will remain the foundation of the repository.

### Improve readability

Handwritten explanations will be rewritten into clear and natural English without changing the intended meaning.

### Organize by topic

Related concepts will be grouped together so that readers can study the material more easily.

### Build incrementally

Each topic will be reviewed, formatted, and committed separately so that the repository remains easy to maintain.

---

## Documentation Format

Each major section will follow a consistent structure where appropriate:

```text
Introduction
Why the topic matters
Core explanation
How it works
Examples from the source notes
Simple analogy
Important concepts
Key takeaways
Next topic
```

The exact format may vary depending on the content available in the original notes.
