# Types of Machine Learning

The notes introduce three major types:

1. Supervised Learning
2. Unsupervised Learning
3. Reinforcement Learning

## Supervised Learning

The model learns from **labelled data**, where the correct answer is already available.

Example: emails labelled as **Spam** or **Not Spam**.

## Unsupervised Learning

The model receives **unlabelled data** and discovers patterns or groups.

Example: grouping customers based on buying behavior, preferences, or spending patterns.

## Reinforcement Learning

An agent learns through actions, rewards, and penalties.

Example: a game-playing system receives a reward for a good move and a penalty for a bad move.

| Type | Training information | Main idea |
|---|---|---|
| Supervised | Labelled data | Learn from known answers |
| Unsupervised | Unlabelled data | Discover patterns or groups |
| Reinforcement | Rewards and penalties | Learn through interaction |
