# Module Overview

This module introduces the core concepts of Artificial Intelligence and Machine Learning.

The content is based on my handwritten AI learning notes and has been rewritten into a structured, easy-to-read format while preserving the original concepts and learning flow.

By the end of this module, you will understand:

- What Artificial Intelligence (AI) is
- How AI is used in everyday life
- What Machine Learning (ML) is
- How Machine Learning works
- Types of Machine Learning
- Neural Networks
- Deep Learning
- Relationship between AI, ML, and Deep Learning

---

# Learning Objectives

After completing this module, you should be able to:

- Explain Artificial Intelligence in simple terms.
- Differentiate AI, Machine Learning, and Deep Learning.
- Understand how Machine Learning models are trained.
- Explain the three major types of Machine Learning.
- Understand the basic concept of Neural Networks.
